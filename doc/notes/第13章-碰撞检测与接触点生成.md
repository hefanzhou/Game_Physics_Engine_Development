# 第13章：碰撞检测与接触点生成

## 概述
第13章详细讲解了如何从碰撞检测中生成接触点（Contact Points），这是物理引擎中连接碰撞检测和碰撞解算的关键环节。

## 接触点生成的基本原理

### 接触点数据结构
```cpp
struct Contact {
    Vector3 contactPoint;    // 接触点位置
    Vector3 contactNormal;    // 接触法线方向
    real penetration;         // 穿透深度
    RigidBody* body[2];      // 参与碰撞的两个刚体
    real friction;           // 摩擦系数
    real restitution;        // 恢复系数
};
```

### 接触类型分类
1. **点-面接触（Point-Face）**：一个物体的顶点与另一个物体的面接触
2. **边-边接触（Edge-Edge）**：两个物体的边接触
3. **面-面接触（Face-Face）**：两个物体的面接触（通常避免使用）

## 各种几何体的接触点计算方法

### 1. 球体与球体碰撞
```cpp
unsigned CollisionDetector::sphereAndSphere(
    const CollisionSphere &one,
    const CollisionSphere &two,
    CollisionData *data
)
```
**计算步骤：**
1. 计算两球心连线向量：`midline = positionOne - positionTwo`
2. 计算距离：`size = midline.magnitude()`
3. 接触法线：`normal = midline * (1.0/size)`
4. 接触点：`contactPoint = positionOne + midline * 0.5`
5. 穿透深度：`penetration = (one.radius + two.radius - size)`

### 2. 球体与平面碰撞
```cpp
unsigned CollisionDetector::sphereAndHalfSpace(
    const CollisionSphere &sphere,
    const CollisionPlane &plane,
    CollisionData *data
)
```
**计算步骤：**
1. 计算球心到平面的距离：`ballDistance = plane.direction * position - sphere.radius - plane.offset`
2. 接触法线：`contactNormal = plane.direction`
3. 接触点：`contactPoint = position - plane.direction * (ballDistance + sphere.radius)`
4. 穿透深度：`penetration = -ballDistance`

### 3. 盒子与平面碰撞
```cpp
unsigned CollisionDetector::boxAndHalfSpace(
    const CollisionBox &box,
    const CollisionPlane &plane,
    CollisionData *data
)
```
**计算步骤：**
1. 检查盒子的8个顶点是否穿透平面
2. 对每个穿透的顶点生成一个接触点
3. 接触法线为平面法线
4. 穿透深度为顶点到平面的距离

### 4. 球体与盒子碰撞
```cpp
unsigned CollisionDetector::boxAndSphere(
    const CollisionBox &box,
    const CollisionSphere &sphere,
    CollisionData *data
)
```
**核心算法：寻找盒子上离球心最近的点**
1. 将球心转换到盒子坐标系：`relCentre = box.transform.transformInverse(centre)`
2. 将球心坐标钳制到盒子边界内：`closestPt = clamp(relCentre, -halfSize, halfSize)`
3. 计算最近点与球心的距离：`dist = (closestPt - relCentre).magnitude()`
4. 如果距离小于球半径，则生成接触点

### 5. 盒子与盒子碰撞（最复杂的情况）
```cpp
unsigned CollisionDetector::boxAndBox(
    const CollisionBox &one,
    const CollisionBox &two,
    CollisionData *data
)
```

#### 分离轴定理（Separating Axis Theorem）
- **原理**：如果存在一个轴，两个物体在该轴上的投影不重叠，则物体不相交
- **盒子碰撞需要检查15个轴**：
  - 3个盒子A的主轴
  - 3个盒子B的主轴  
  - 9个主轴叉乘得到的轴（3×3）

#### 接触点生成策略
1. **点-面接触检测**：检查每个盒子的顶点是否穿透另一个盒子
2. **边-边接触检测**：检查盒子边的最近点
3. **选择最深的穿透**：只返回穿透最深的接触点，避免多接触点的不稳定性

## 接触点生成的关键技术

### 1. 穿透深度计算
- 对于球体：半径和减去实际距离
- 对于盒子：使用分离轴定理计算最小穿透
- 对于复杂形状：使用GJK或V-Clip算法

### 2. 接触法线确定
- 球体碰撞：两球心连线方向
- 平面碰撞：平面法线方向
- 盒子碰撞：分离轴方向或面法线方向

### 3. 接触点位置计算
- 通常取穿透区域的中心点
- 对于边-边接触：计算两条边的最远点连线中点

## 实现细节与优化

### 早期退出优化
```cpp
// 球体与盒子碰撞的早期检查
if (real_abs(relCentre.x) - sphere.radius > box.halfSize.x ||
    real_abs(relCentre.y) - sphere.radius > box.halfSize.y ||
    real_abs(relCentre.z) - sphere.radius > box.halfSize.z)
{
    return 0; // 无碰撞，提前退出
}
```

### 接触点缓存
- 利用时间连贯性：相邻帧的接触点可能相似
- 缓存特征对（如特定的顶点-面组合）
- 只更新穿透深度和接触位置，减少重复计算

### 数值稳定性
- 避免除零错误：检查向量长度是否接近零
- 使用容差值处理浮点精度问题
- 法线向量归一化处理

## 实际应用考虑

### 性能优化
1. **层次包围体**：快速排除不可能碰撞的物体对
2. **空间分割**：使用BSP树、四叉树、八叉树等数据结构
3. **多分辨率碰撞**：根据距离使用不同精度的碰撞检测

### 物理真实性
1. **避免面-面接触**：使用多个点-面接触代替，提高稳定性
2. **边-边接触处理**：确保力矩传递的正确性
3. **穿透纠正**：合理的穿透深度计算避免物体"卡住"

## 总结

接触点生成是碰撞检测到碰撞解算的桥梁，其核心是：
- **准确计算穿透几何**：确定物体如何相交
- **合理选择接触点**：确保物理解算的稳定性  
- **高效算法设计**：平衡精度和性能需求

第13章提供的算法为各种基本几何形状的碰撞提供了可靠的接触点生成方案，是构建完整物理引擎的基础。
